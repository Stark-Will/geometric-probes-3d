# Showcase geometry-check figures

Textured render (left) and grey geometry view (right) for public modelfy.art showcase models, produced with the checks in `geomcheck/` (CPU-only, deterministic, ~2 s per model). These are educational examples of how to read each check, not a benchmark. Per-model numbers: see `results/` and the paper.

- `showcase_contact_sheet.png`: all 18 showcase models.
- `check_blacksmith.png`: thin walls (roof plates) to thicken before printing.
- `check_wedding.png`: inner (hidden) layers to simplify for printing or games.
- `check_dwarf.png`: thin-wall marks on blades, shield rim and clothing edges.
- `check_hammer.png`, `check_chair.png`: simple models close to print-ready.
